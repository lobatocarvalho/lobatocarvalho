## Profile

Software engineer from Timor-Leste specializing in **Django and Python backend development**. I design and build secure, maintainable web applications and APIs, with particular interest in **financial technology and microfinance systems**.

My work focuses on clean architecture, reliable data models, containerized deployment, and automation through CI/CD.
